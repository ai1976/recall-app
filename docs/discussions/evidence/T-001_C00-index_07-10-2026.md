## 3. Claude's reading (analysis, NOT evidence; for QA to audit)
- **The decision rule of the file header fires: nulls exist (671), so C-01 may not leave the null date undefined.** The column is nullable by design of the table, not by accident of the repository docs.
- **How the live functions treat these rows (from saved RUN 1B, not from this run):** the Review page's `get_study_queue` requires `r.next_review_date <= v_today`, which is not true for a null, so a null row is **never offered for review**; the forecast cumulative counts never count it either; the live `get_due_forecast_buckets` places a null date in **bucket 7** (the farthest bucket), so Forward Load shows these rows as work due later even though no function will ever offer them. The 590 active rows are therefore **neither due nor reviewable**: they cannot be graded, so their date cannot be set by the normal path. (An `unsuspend_card` call sets the date to today, per the saved text of the re-add path, which would change the 81 suspended ones; this was not tested.)
- **Cause: OPEN.** The rows were created between 02/01/2026 and 19/01/2026, all have a last-reviewed time, and belong to 14 users. This run does not say why the date is null. No data repair is authorized or proposed here.
- **What this means for brief C:** the existing text of brief C v5 (C-6.2) says the brief is revised to define the null behaviour explicitly when nulls exist. Claude proposes the definition in brief C v6 (Round 89): a null date is **not due and is excluded from every bucket**, matching the Review page; Forward Load will show up to 590 fewer items in bucket 7 for 14 users, a visible and intended correction; the cause and any repair stay a separate decision.
- **What this evidence does not show:** why the dates are null; whether any live client or function can still create a new null row (the only writers seen are `apply_review` and the My Cards functions, read in saved evidence, not re-read here); anything about enrollment, course or visibility of the null rows; runtime behaviour of the callees beyond their text.
