## 7. B-05 `flashcards` and `notes`
**Principle.** `target_course` (T) is a derived label for platform rows (brief B 6.3). A row is *platform* when it has a subject S or a discipline D. DS is the discipline of S; name(X) the exact discipline name. An unknown S or D raises a clear error. The trigger fires only when S, D or T is inserted or `IS DISTINCT FROM` its old value.

**Conflict test (NULL-safe, `IS DISTINCT FROM` throughout).** A stored row is a *conflict* if: S is not NULL and ((D IS NOT NULL AND D IS DISTINCT FROM DS) OR T IS DISTINCT FROM name(DS)); or S is NULL and D is not NULL and T IS DISTINCT FROM name(D). A NULL T on a platform row is therefore a conflict. (D2 counts the rows that meet this definition.)

**Precedence.** (1) On UPDATE, evaluate the **OLD row** first. If it is a conflict and any of S, D, T changed, the update is **refused** with a clear message ("flagged as a conflict; reconciliation is a separate reviewed fix"). It is never accepted and never repaired (brief B 6.2). Updates that change none of S, D, T do not fire the trigger and succeed. (2) Otherwise apply the after-state rows below.

| After-state (non-conflict rows, and every INSERT) | Result |
|---|---|
| S set | If D is explicit (inserted non-NULL, or changed) and not NULL and D IS DISTINCT FROM DS: **refuse**. Otherwise D := DS and T := name(DS). Covers INSERT with S; S only; S+T; S+D with D = DS; S+D+T; D changed to NULL with S set; T only on a row with S (the current batch edit sends S and T together, `MyFlashcards.jsx:463`) |
| S NULL, D NULL, T resolves to a discipline name (`resolve_canonical_course_label` exact match) | D := that discipline, T := its exact name |
| S NULL, D NULL, T anything else | untouched (custom course or unassigned) |
| S NULL, D explicit non-NULL | platform by discipline: T := name(D); D must exist |
| S NULL after the operation, D carried unchanged, and S changed to NULL or T changed (platform-to-custom or platform-to-discipline-only edit, or a T-only edit of a discipline-only row; the screens do not send D) | resolve the new T: a discipline name gives D := that discipline, T := exact name; any other T gives D := NULL and T stored as supplied. If T is unchanged: T := name(D) |
| none of S, D, T changed | not fired |

Every row, and every combination of changed columns (the seven non-empty subsets of {S, D, T}) with valid, NULL and unknown identifiers, is a TEST case, plus the conflict-refusal cases (S set with T NULL; S NULL, D set with T NULL). D4 evidence may correct the table **before** B-05 is authored. The notes path is checked column by column against D2 before assuming it matches `flashcards`.
